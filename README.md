# FarmSync AI: Multi-Game Save Sync, AI Translation & Mod Companion for Android

[![Platform](https://img.shields.io/badge/Platform-Android%2014%2B%20%2F%20HyperOS-blue.svg)](https://developer.android.com)
[![Shizuku](https://img.shields.io/badge/Shizuku-API%2013%2B-green.svg)](https://shizuku.rikka.app)
[![Architecture](https://img.shields.io/badge/Architecture-Clean%20%2B%20Compose-purple.svg)](https://developer.android.com/jetpack/compose)

FarmSync AI is a high-performance Android companion application designed for cross-platform save game synchronization (Google Drive / Local Server), intelligent AI mod translation with character persona preserving, and real-time dynamic story injection for games like Stardew Valley.

## Key Features
- **Direct Scoped Storage Access:** Native Shizuku IPC binder integration for seamless `/Android/data` access without root.
- **Save Game Collision & Conflict Matrix:** In-game timeline analyzer (Year/Season/Day/Money) with rolling 10-slot snapshots.
- **AI-Powered Mod Localization:** Stardew syntax tag protection (`%firstname`, `^`, `$e`) and persona-aware Thai translation using Gemini 2.0.
- **Dynamic Story Chronicle & HD Art Engine:** Real-time in-game mail/quest injection via Content Patcher and HD PNG texture formatting.
- **Xiaomi HyperOS Direct Optimization:** Dedicated background keep-alive and 1-tap system settings guide.
